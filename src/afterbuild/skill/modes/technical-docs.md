# Technical Documentation Mode

## Structure
- Overview
- Architecture
- API Reference
- Configuration
- Development Workflow
- Testing
- Deployment

## Voice
Precise and detailed. Assume the reader is a developer familiar with the technology stack but new to your project.

## Interview Questions
1. What programming language/framework does this use?
2. What is the high‑level architecture?
3. Where is the entry point or main module?
4. What are the key dependencies?
5. Are there any environment variables or config files?

## Writing Rules
- Include a diagram if possible (ASCII art is fine)
- Document all public APIs with parameters and return values
- Explain any non‑standard design decisions
- List all configuration options with their defaults
- Include examples of common use cases
- Reference any related documentation or standards
