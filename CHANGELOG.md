# afterbuild Changelog

## [0.1.0] (2026-11-07)

### Added
- Initial implementation of the afterbuild CLI
- Analyze command to generate project brief
- Verify command to check draft documents
- Export command to render documents to various formats
- Init command to install the bundled skill
- Support for multiple document modes (product-docs, technical-docs, research-report, storytelling, case-study)
- Basic testing framework with pytest
- GitHub Actions CI/CD setup
- Documentation (README, CONTRIBUTING)

## [0.0.1] (2026-11-07)

### Initial release

- First commit with basic scaffolding
- pyproject.toml and package structure
- CLI entry point and subcommands
- Analyze, verify, export, modes, doctor commands
- Skill and mode markdown files
- Basic tests
