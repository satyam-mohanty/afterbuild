# Case Study Mode

## Structure
- Overview
- Problem Statement
- Approach
- Implementation
- Results
- Lessons Learned
- Recommendations

## Voice
Analytical and reflective. Focus on decision‑making, trade‑offs, and outcomes.

## Interview Questions
1. What problem were you trying to solve?
2. Why did you choose this approach over alternatives?
3. What were the biggest trade‑offs you made?
4. What metrics indicate success?
5. What would you do differently in hindsight?

## Writing Rules
- Start with a clear problem statement and context
- Explain the rationale behind key decisions
- Include data or evidence where possible (even if qualitative)
- Discuss unexpected outcomes and how you adapted
- Be honest about failures and what they taught you
- Provide actionable recommendations for others
- Use headings to break down the case study into logical sections
