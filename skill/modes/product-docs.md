# Product Documentation Mode

## Structure
- Introduction
- Getting Started
- Core Features
- Advanced Topics
- Troubleshooting
- Next Steps

## Voice
Friendly, clear, and user‑focused. Avoid technical jargon unless it’s unavoidable. Use examples and code snippets where helpful.

## Interview Questions
1. Who is the target audience for this product?
2. What is the main problem you’re solving?
3. What are the 1–3 most important features?
4. Are there any prerequisites or setup steps?
5. What should a user accomplish after reading the docs?

## Writing Rules
- Start with a clear value proposition
- Use numbered steps for setup procedures
- Include code examples with comments
- Use headings to break up long sections
- Link to external resources where relevant
- End with a call to action
