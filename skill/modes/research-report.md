# Research Report Mode

## Structure
- Abstract
- Introduction
- Related Work
- System Design
- Implementation
- Evaluation
- Limitations
- References

## Voice
Academic and formal. Cite real sources with hyperlinks. Base all claims on code or the brief.

## Interview Questions
1. What novel claim or insight does this project demonstrate?
2. What related work or papers should I reference?
3. What metrics or benchmarks are relevant?
4. What are the main limitations or areas for future work?
5. Is this part of a larger research initiative?

## Writing Rules
- Start with a concise abstract summarizing the contribution
- Use section headings and numbered lists for clarity
- Include citations in the format [Author, Year] with hyperlinks
- Describe the evaluation methodology and results
- Acknowledge limitations honestly
- End with concrete future work directions
- Never invent numbers or benchmarks – mark as TODO if unknown
